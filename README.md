# 本地生活商家咨询 AI 助手评测

一套面向抖音生活服务和美团／大众点评商家咨询的评测集，用来检查 AI 客服能否按平台规则回答，并给商家一个可执行的下一步。题目覆盖团购、上架、核销和佣金。

## 评测规模

- **89 道题**来自 37 个官方出处，其中 14 道为公开问答原题、36 道为公开问答改写、39 道由规则派生。题库包含原始出处、参考答案、必答点与错误判据。
- 两版提示词使用相同题目与规则资料。评分覆盖准确性、幻觉控制、话术友好度和答复边界，并单独标记严重错误。
- 已保存 **48 条逐题实测回复及评分**，另有千问两次整批拒答记录。

## 实测结果

| 入口 | 共同试测集 V0 | 共同试测集 V1 |
| --- | --- | --- |
| GPT（Codex） | 通过 5/6 | 通过 6/6 |
| 豆包网页版 · 快速 | 通过 2/6 | 通过 4/6 |
| 千问国内网页版 · Qwen-快速 | 整批拒答，逐题覆盖 0/6 | 整批拒答，逐题覆盖 0/6 |

在验证码场景中，豆包 V1 明确拒收验证码，并指引商家打开对应订单的账单查看扣费项目。豆包 V1 仍漏掉赠品供应条件和提前核销场景中的预约留位办法。

共同试测为 6 题，每版仅生成一次。GPT 另跑了 12 道留出题。结果适合定位答复问题，生产选型仍需扩大逐题样本并固定模型快照。

## 复跑

脚本使用 Python 3 标准库。以下命令只检查试测题号和请求数量。

```text
python run_eval.py --provider doubao --model MODEL_ID --split pilot --dry-run
```

实际运行时，换成已开通的模型 ID，设置对应的 `OPENAI_API_KEY`、`DASHSCOPE_API_KEY` 或 `ARK_API_KEY`，去掉 `--dry-run`。用 `--limit 1` 可先验证一题，结果写成 JSONL。API 逐题复跑与报告中的网页版分组试测采用不同提交方式。
